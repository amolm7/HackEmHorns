# Visual workspace

The interface centers on doing one thing at a time. The former IDE shell, configuration example, onboarding essays, and home metric panels have been removed.

- Home: four illustrated skill cards, one creation action, existing agents, and an approval banner only when attention is needed.
- Creation: describe a job or select skills, then review. A home skill selection carries through to the creation screen. Model and organization settings remain collapsed.
- First task: a compact Create → Task → Review strip replaces instructional paragraphs. Examples fill the task composer. Demo mode stays clearly labeled.
- Review: actual action previews remain visible. Approve, send back, and reject keep their original backend behavior.
- Reuse: managers can share a template directly from the agent header. Library installation still requires local connection validation.
- Team jobs: optional disclosure; opens when jobs exist. Assignment, artifacts, and outcome review are preserved.

Appearance: dark navy canvas, electric-blue actions, icy typography, connected-agent illustration, and blue glass skill cards. Theme analysis and execution plan: `docs/THEME-PLAN.md`. Short labels, visible focus outlines, and reduced-motion support remain.

Verification: JavaScript syntax and whitespace checks; renders for five main screens; four starter cards; preserved selected skill; creation confirmation; first task form and progress guide; optional team assignment. The browser preview could not be fully verified because native browser control stopped responding reliably. Backend workflow is unchanged.
