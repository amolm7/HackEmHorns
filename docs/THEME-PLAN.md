# Paradigm × Datacore theme

## References reviewed

- [Paradigm by Phenomenon](https://dribbble.com/shots/26100872-Paradigm-Tech-Consulting-Landing-Page): all six linked case-study images, including desktop hero, mobile service/contact, industries/workflow, mission/stack, mobile brand/support, and global presence. The separate video was not reviewed.
- [Datacore by Outcrowd](https://dribbble.com/shots/27043865-Datacore-Website-for-an-API-First-AI-Platform): three publicly indexed artwork images covering the hero, three-step workflow, documentation, and feature accordion. The direct browser page did not render, so these public source images and the page description were used.

## Analysis

| Pattern | Paradigm | Datacore | Application adaptation |
| --- | --- | --- | --- |
| Canvas | Near-black with teal/cyan light | Near-black with deeper blue light | Dark navy, restrained blue atmosphere |
| Type | Large, pale blue, spacious | Geometric, centered, gradient headline | Readable local Hanken Grotesk; short centered hero |
| Surfaces | Thin edges, glints, technical illustrations | Glass cards, modest rounding, blue bases | Clear bordered cards, hover lighting, selected state |
| Composition | Hero drama, spacious sections, mobile detail | Modular panels, linear workflow | Four actionable skill cards and one connected-agent illustration |
| Accents | Cyan outlines and glow | Electric blue CTA and circuit lines | Blue actions, cyan highlights; amber reserved for review |
| Content | Marketing services and global reach | API benefits and previews | No added marketing sections, fake metrics, code samples, or testimonials |

The references are design artwork, not functioning applications. Their decorative density is reduced for a working tool. Forms keep ordinary labels, and approval previews retain the exact action evidence.

## Step-by-step execution

1. Replace the light palette with shared dark tokens; set typography and navigation.
2. Recompose home: a short centered title, one action, and an original vector diagram of skills → agent → human review. The diagram illustrates the workflow, not live activity.
3. Apply the theme to skill cards, agent cards, builder, composer, results, library, and approvals. Maintain visible focus and text-based statuses.
4. Add short entrance transitions and a finite connector-light animation. Keep forms still during polling. Honor reduced motion.
5. Verify JavaScript and whitespace; render main screens and key states; check the running app and end-to-end workflow. Document any browser verification limits.

## Scope

Frontend theme only. Preserve API routes, agent specs, model configuration, connections, approval policy, marketplace, and all current navigation. Keep advanced settings collapsed and the two-step builder intact. No third-party design assets are shipped; diagrams and icons are original code-native SVG/CSS.
